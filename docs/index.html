EasyNFC

Lê um QR code e grava-o num autocolante NFC, diretamente no teu Android.

Descarregar APK para Android
  1. Transfere o APK para o teu telemóvel Android.
  2. Abre o ficheiro e permite a instalação desta origem, se for pedido.
  3. Abre a app e permite o acesso à câmara e ao NFC.

Este APK é uma compilação de teste distribuída fora da Play Store. A instalação é apenas para Android; precisas de um telemóvel com NFC para gravar etiquetas.
